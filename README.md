Hyprland + Waybar + Dunst + Alacritty + Rofi + htop + gtk-3.0 + niri + gpu handling + sleep handling + Arch install guide for my specific laptop hardware - Lenovo Legion 5 ryzen 5 4600 h, nvidia gtx 1650 gpu, 8gb/16gb ram, 512 ssd.

Remember to check hyprland wiki for multi-gpu setup to create a symbolic link to always point to amd-igpu.
Remember to have authentication agent, password storage and all for brave to open properly.
